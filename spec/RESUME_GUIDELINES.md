# Honest resume and interview presentation

## How to showcase the completed project
- Link public source repo; include a screenshot of the **actual generated** report, with a caption indicating synthetic models/inputs.
- Demo command must run on a standard CPU system.
- Show one intentionally caused and correctly detected failure, fully labeled as injected/simulated.
- Present architecture and tests, not aspirational claims.
- Commit a representative example report only if it contains no sensitive paths/identifiers; otherwise use screenshots.
- Include exact tested OS, Python/PyTorch/ONNX versions, number of tests run, and observed counts only after verifying.

## Safe resume bullet template — customize after completion
- Built [implemented scope] with Python, PyTorch, ONNX, and ONNX Runtime; automated [specific real checks] across [actual model/test categories].
- Added [real debugging or reporting feature] and `pytest`/Linux CI; measured [actual factual results with baseline/caveats].

**Do not claim:** production accelerator access, physical semiconductor board validation, proprietary AMD/NVIDIA programming, achieved speedups, 100% test coverage, or accuracy that was not actually measured.
